# 🤖 Dota 2 News & Stream Bot

Telegram-бот для автоматического сбора новостей и аналитики по Dota 2. 
Проект демонстрирует навыки работы с API, парсинга данных и автоматизации рутины на Python.

## 🛠 Технологии и библиотеки
- **Python 3.10+**
- **aiogram** — фреймворк для Telegram-бота
- **requests / BeautifulSoup** — для парсинга веб-страниц
- **pandas** — для обработки табличных данных (если использовал)
- **AI-assisted development** — прототипирование и генерация кода с помощью LLM
